# @pangular-inspector/devtools

Pangular Inspector, the unified Angular devtools. Inspect component trees, signals, dependency injection, routes, forms, pipes and NgRx stores in a running Angular app, from a static report, or through a coding agent over MCP. It works with Angular CLI apps, SSR, Analog, NativeScript and Angular Native.

## Install

```sh
npm install @pangular-inspector/devtools devframe
```

Then pick the setup for your app in the [installation guide](https://pangular-inspector.dev/getting-started/installation/).

## Try it without installing

Run it from the root of your Angular workspace:

```sh
npx @pangular-inspector/devtools dev
```

It starts a local server and prints the panel URL. The panel shows what it finds in your source. For a coding agent, run `npx @pangular-inspector/devtools mcp`.
